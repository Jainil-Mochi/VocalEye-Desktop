# Setup

1. Install the .NET 10 SDK and Visual Studio 2022 (17.13+) or later with the ".NET desktop development" workload.
2. `dotnet restore VocalEye.Desktop.slnx`
3. `dotnet build VocalEye.Desktop.slnx`
4. `dotnet test VocalEye.Desktop.slnx`
5. Run the app: `dotnet run --project src/VocalEye.Desktop.App`
6. Run the spike: `dotnet run --project spikes/ChatSpike`
